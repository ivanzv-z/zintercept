# Seguridad

## Avisar de un fallo de seguridad

Si encuentras una vulnerabilidad en ZIntercept, **no abras una sugerencia pública**.

Usa el aviso privado de GitHub: pestaña **Security** → **Report a vulnerability**
(https://github.com/ivanzv-z/zintercept/security/advisories/new).

Ese aviso solo lo vemos tú y el autor. Cuando esté corregido, se publicará con tu permiso
y se reconocerá tu aportación si quieres.

## Qué datos maneja ZIntercept

- Todo el tráfico que intercepta se queda **en tu equipo**. ZIntercept no envía nada a ningún servidor.
- Los botones de *sugerir una mejora* y *web de Iván Z* solo abren tu navegador. No adjuntan nada:
  la sugerencia solo lleva rellenos la versión y el sistema operativo.
- La CA que genera ZIntercept se guarda en tu perfil de usuario y solo la usa el navegador de pruebas
  que abre la propia app.

## Versiones con soporte
